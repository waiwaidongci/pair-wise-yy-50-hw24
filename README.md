# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 复核记录（豁免 / 预检 / 版位同一份账）

- 每条放行豁免绑定**问题指纹**（规则类别 + 规则版本 + 问题参数）和**当次版位摘要**（全张 digest + 相关版位/出血/装订快照），口头放过不再被接受。
- 拖动版位、修改页面出血或装订方向后，相关豁免**立即失效并重新校验**；失效与放行同样写审计。审批锁定记录所依据的摘要与版本，版位变化后总览与版本对比显示“依据已过期”。
- 两个工位同时保存时只接受**打开页面时的文档版本**：后到方收到冲突提示并列出被改对象（坐标 / 出血 / 装订 / 锁定 / 他站放行），以最新版本重开后保留填写内容，并按**原记录号**重试。
- 豁免与审计在同一事务落库，写入失败不会留下“只有豁免没有审计”的半批结果；按原记录号重试是幂等回放。
- 旧数据升级时，缺少指纹的历史豁免一律标为**待复核**，可在“复核记录”页补绑当前指纹确认或驳回（历史理由与审计仍可查看）。总览、拼版预检、版本对比三处显示相同的待复核数量。

### 联调入口

拼版工作区底部“并发 / 故障联调”可模拟：另一工位先拖动版位 / 换 P7 出血 / 先锁定（触发版本冲突并列出被改对象），以及注入一次写入失败（验证原记录号幂等重试）。

核心逻辑（指纹失效检测、乐观并发、幂等提交、旧数据迁移）有可独立运行的断言测试：

```bash
node scripts/test-ledger.mjs
```
